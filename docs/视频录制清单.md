# Job Hunting Helper｜录屏与剪辑清单

本清单配合 [视频演示脚本](视频演示脚本.md) 使用。目标是一条约 3 分 30 秒的项目介绍视频：**真实录屏、本人配音、少量字幕与标题卡**。画面按 A→G 顺序拍摄，顺序不对也没关系，按下面的文件名保存即可。

## 开录前 10 分钟

- [ ] 浏览器以 16:9 画面录制，建议 1920×1080、30 fps；页面缩放到文字清晰可读，录屏区域不要包含个人桌面和其他标签页。
- [ ] 关闭系统通知、开发者工具和无关窗口；让鼠标缓慢移动，点击后停留约 1 秒。
- [ ] 选好一条可公开展示的岗位、一条「仅沟通」会话、一条有交换且可展示发送核对状态的会话，以及已经生成的图表。优先使用测试或可匿名化数据。
- [ ] 检查画面中的姓名、头像、聊天原文、简历内容、API Key、邮箱和岗位 ID；能在录前隐藏的先隐藏，余下的在剪辑时遮挡。
- [ ] 图表区关闭「生成前重新扫描」，避免为录制触发监测任务。不要实际点击发送招呼、追问或删除。

macOS 可以用 `Shift + Command + 5` 录制选定区域。每个镜头多录前后各 2 秒，剪辑时才有余量。原始录屏和配音含私人信息，建议放在本机非仓库目录，不提交到 GitHub。

## 要拍的画面

| 镜头 | 建议文件名 | 页面与操作 | 可用时长 |
| --- | --- | --- | --- |
| A1 | `A1_岗位列表.mov` | 采集任务 → 已入库岗位，缓慢滚过 2–3 条岗位 | 5–7 秒 |
| A2 | `A2_会话列表.mov` | 监测任务 → 仅沟通，显示几条不同状态的会话 | 5–7 秒 |
| A3 | `A3_工作台.mov` | 工作台全景，停在采集、监测执行记录 | 5–7 秒 |
| B | `B_项目揭示.mov` | 工作台顶部，从页面标题缓慢移向图表区域 | 8–10 秒 |
| C1 | `C1_配置.mov` | 配置 → 岗位来源与岗位要求，展示推荐流、搜索流和条件 | 12–16 秒 |
| C2 | `C2_采集任务.mov` | 采集任务 → 最新执行记录、当前配置、岗位列表的来源列 | 16–20 秒 |
| D | `D_岗位详情.mov` | 在岗位列表搜索并打开一条示例岗位，展示要求、评分理由、招呼语草稿 | 24–30 秒 |
| E1 | `E1_仅沟通.mov` | 监测任务 → 仅沟通，展示已读状态和追问状态 | 12–15 秒 |
| E2 | `E2_有交换.mov` | 切换有交换，展示附件简历的「已确认发送／未确认发送」 | 12–15 秒 |
| E3 | `E3_新会话.mov` | 切换新会话，停留在任务卡和列表即可 | 5–7 秒 |
| F1 | `F1_执行记录.mov` | 工作台 → 今日和历史执行记录 | 8–10 秒 |
| F2 | `F2_桑基图.mov` | 工作台 → 生成图表，悬停一条路径，让其他路径置灰 | 16–20 秒 |
| F3 | `F3_折线图.mov` | 切到折线图，依次点击两个主题，停留看曲线变化 | 16–20 秒 |
| G | `G_工作台结尾.mov` | 工作台全景，画面静止或缓慢滚动 | 8–10 秒 |

**不需要每个镜头都拍一遍完整操作。** 先停在正确页面，再开始录该段，会比在视频里等待加载更顺畅。图表生成如果比较慢，保留按钮点击和最终结果，剪掉中间等待。

## 配音

照着 [旁白净稿](视频口播稿.md)，以平时讲项目的语气读一遍即可。用安静房间和耳机麦克风或手机录音；录成一个 `旁白.m4a` 或 `旁白.wav` 文件。段落之间停 1 秒，读错就从上一句重读，剪辑时可处理。标题和代码名不必刻意念英文全称。

## 剪辑顺序与文字

1. **0:00–0:22，提出问题。** A1、A2、A3 快切；依次加「看过了吗？」「聊过了吗？」「简历发了吗？」。最后停半秒。
2. **0:22–0:43，展示产品。** B 画面上加项目名与一句话「让求职进展有迹可循」。
3. **0:43–1:56，采集与判断。** C1 → C2 → D；只在「推荐流 / 搜索流」「岗位来源」「评分理由」三处加简短标注。
4. **1:56–2:35，监测。** E1 → E2 → E3；当旁白说「有交换不等于已投递」时，画面同时指向发送核对状态。
5. **2:35–3:13，复盘。** F1 → F2 → F3；桑基图悬停和折线图主题切换各保留完整动作。
6. **3:13–3:30，结尾。** G 后切 [片尾卡](video-assets/end-card.png)，保留项目地址 2–3 秒。

字幕按实际配音对齐；语句短一些，一屏最多两行。转场以直接切镜头为主，图表段落可用轻微推进。背景音乐保持很低，避免盖住配音；即使完全不加音乐也成立。

## 完成前检查

- [ ] 每个数字、状态和旁白都与录到的真实界面一致。
- [ ] 私人信息在暂停、逐帧查看时也无法读出。
- [ ] 没有真实发送、追问或删除动作被误放进演示。
- [ ] 全片 1080p 横屏，声音清楚，字幕没有挡住表格关键列。
- [ ] 开头 10 秒就能听明白问题；结尾能看到项目名称和仓库地址。
